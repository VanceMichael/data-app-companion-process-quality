# 资料契约

所有记录均为本地合成演练资料，不含真实个人、企业或医疗信息。文件使用 UTF-8 JSON，金额和数量以各字段说明为准。空串、零、缺报、争议分别保留其含义，不可互相替换。

记录的 `id` 只在本资料类别内唯一。`known`、`known_day`、`known_week`、`known_month` 表示收到事实的时间；实际发生时间另有字段。日序和分钟是演练的相对时间，未另行说明的区间均左闭右开。月份为演练年度的自然月。

`data/schema.json` 声明字段、类型和显式引用。数组与对象内的业务关系按相应中文字段说明解释；资料检查器不替代这些业务关系的判断。原始与后补记录共存，文件排列不代表业务生效顺序。

## visits

匿名辅助服务及复杂程度。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 服务 |
| `customer` | string | 客户 |
| `type` | string | 服务型 |
| `complexity` | string | 复杂度 |
| `contract` | string | 合同 |
| `service_day` | integer | 服务实际日序 |

## contracts

费用与责任约定，不涉及诊疗。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 合同 |
| `rate_cents_per_hour` | integer | 每小时分 |
| `free_wait_minutes` | integer | 免费候诊 |
| `continuous_handover` | boolean | 转接连续计时 |
| `unfinished_refund_fraction` | number | 未完成事项退费比例 |

## obligations

事项依赖是业务要求，允许并行；新增标记与原约定不同。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 事项 |
| `visit` | string | 服务 |
| `kind` | string | 辅助事项 |
| `depends_on` | array | 依赖事项 |
| `required_recipient` | string | 交接接收方 |
| `origin` | string | 原约定或新增 |

显式引用：`visit` → `visits.id`。

## events

时间为分钟；记录可冲突，由复核采用。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 记录 |
| `visit` | string | 服务 |
| `obligation` | string | 事项 |
| `actor` | string | 提交方 |
| `minute` | integer | 实际分钟 |
| `kind` | string | 开始或结束或交接或取消或暂停 |
| `recipient` | string | 接收方或空 |
| `reason` | string | 原因 |
| `known_day` | integer | 知悉日 |

显式引用：`visit` → `visits.id`；`obligation` → `obligations.id`。

## waiting

医院等待的可证实区间。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 等待 |
| `visit` | string | 服务 |
| `start` | integer | 起 |
| `end` | integer | 止 |
| `verified` | boolean | 已核实 |

显式引用：`visit` → `visits.id`。

## handoffs

不同工作人员接手区间。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 接手 |
| `visit` | string | 服务 |
| `worker` | string | 人员 |
| `start` | integer | 起 |
| `end` | integer | 止 |
| `material_confirmed` | boolean | 接手材料已确认 |

显式引用：`visit` → `visits.id`。

## adjudications

后补证据的正式采纳。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 裁定 |
| `visit` | string | 服务 |
| `target` | string | 原记录 |
| `finding` | string | 采用事实 |
| `known_day` | integer | 知悉日 |

显式引用：`visit` → `visits.id`。

## payments

已收客户费用及改进安排。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 支付 |
| `visit` | string | 服务 |
| `amount_cents` | integer | 金额 |
| `day` | integer | 日序 |

显式引用：`visit` → `visits.id`。

## improvements

改进针对偏离类别，结项不裁定未决责任。

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | string | 改进 |
| `kind` | string | 类别 |
| `start_day` | integer | 起 |
| `complete_day` | integer | 结束 |
| `workers` | array | 人员 |
